# Desafio Front End Júnior

Projeto criado para teste técnico

## Como Rodar

* Primeiro: Baixar projeto com git clone

```js
git clone https://github.com/OrionAishe/desafio-front-end-junior
```

* Segundo: Instalar as dependências do projeto

```js
npm install
```
* Terceiro: Rodar o projeto na máquina

```js
npm run dev
```

## Dependências Utilizadas

* Vite
* Material-UI
* Axios
* React Router
* React Hook Form
